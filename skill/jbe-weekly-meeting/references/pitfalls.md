# 자주 틀리는 자리

먼저 읽으면 4단계(화자·교정 채우기) 시간이 크게 준다.

## 부서명은 거의 매번 틀린다

받아쓰기가 부서명을 제대로 들은 적이 드물다. 4회차를 돌리는 동안 **부서명 오인식 규칙만 31개**
쌓였다(전체 사전 110개 중). 실제로 나온 것들:

| 들린 대로 | 실제 |
|---|---|
| 제목과 / 재무가 | 재무과 |
| 검사관실 / 감사가님 / 감사관 씨를 | 감사관실 |
| 정책계과 / 정책계획과 / 다 어 정책과 | 정책기획과 |
| 문회체학과 / 문의시공원과 / 문해체공학과 / 문외체건강가 | 문예체건강과 |
| 장애인지교육과 / 장인재교육가 / 장애인재교육과 | 창의인재교육과 |
| 네 예상과 / 예상과 | 예산과 |
| 노사협력가 / 교육협력가 | 노사협력과 / 교육협력과 |
| 미래교육정치연구소 | 미래교육정책연구소 |
| 학교안정과 | 학교안전과 |
| 유초특수교육과 | 유초등특수교육과 |
| 총무가 | 총무과 |

**같은 부서가 회차마다 다르게 들린다.** 새 변형이 나오면
`collector/glossary.json` 의 `replacements` 에 넣는다. `data/human/` 이 아니다 —
사전에 넣어야 다음 회차에서도 자동으로 걸린다.

부서명은 `references/departments.json` 의 20개 중 하나여야 한다.
없는 이름을 지어내지 않는다. 예전에 `학생생활과` 라는 없는 과를 만들어 낸 적이 있다.

## 군집이 두 사람을 섞는다

목소리가 비슷하면 다른 부서 담당자가 한 군집에 묶인다. 실측 사례:

- 미래교육과(2:54)와 중등교육과(6:19)가 같은 군집
- 총무과(18:03)와 재무과(20:11)가 같은 군집
- 감사관실(9:10)과 노사협력과(22:24)가 같은 군집

**시간대로 갈라야 한다.** 회의는 부서가 순서대로 보고하므로, 한 군집이 서로 떨어진
시간대 두 곳에 나타나면 다른 사람일 가능성이 크다. 교육감이 "다음 ○○과로 가시죠" 라고
부른 자리를 기준으로 나눈다.

반대로 **짧은 맞장구는 엉뚱한 군집으로 튄다.** "네.", "홍보도 좀 해 주시고." 같은 것.
`merge_same_speaker()` 가 앞뒤 화자가 같으면 붙여 주지만, 화자를 채우기 전에는 안 붙는다.

## 받아쓰기가 삼키는 자리

자막 대조가 자동으로 잡아 주지만, 어떤 구간이 그런지 알아 두면 결과를 볼 때 도움이 된다.

- **부서 보고의 첫 문장** — "네, ○○과 말씀드리겠습니다. 1번입니다." 가 통째로 없어진다.
  실제로 재무과와 정책기획과의 도입부가 사라졌다.
- **마이크에서 먼 발언** — 다시 받아써도 안 나온다. 자막에서 가져온다.
  W33은 이런 구간이 7곳으로 유난히 많았다.
- **회의 맨 끝** — "없으면 이 정도에서 마치겠습니다" 근처가 자주 얇게 나온다.

## 교육감 발언에서 자주 깨지는 말

| 들린 대로 | 실제 |
|---|---|
| 주관 정책회의 / 주간 정책일 | 주간정책회의 |
| 일히 일비 | 일희일비 |
| 관부님들 | 간부님들 |
| 종이 결제 / 전자 결제 | 종이 결재 / 전자 결재 |
| 내시화 / 내시게 | 내실화 / 내실 있게 |
| 청년 콘텐츠 공모전 | 청렴 콘텐츠 공모전 |
| 추가경쟁예산 / 추가경영예산 | 추가경정예산 |
| 독렬을 하고 | 독려를 하고 |
| 언어민 보조교사 | 원어민 보조교사 |

`청렴`이 `청년`으로 들리는 게 특히 잦다. 감사관실 보고에서 매번 나온다.

## 요약을 쓸 때

- **인용문은 회의록에서 복사한다.** 기억으로 쓰거나 다듬지 않는다.
  다듬고 싶으면 `text`(요약문)에서 하고 `quote`는 그대로 둔다.
- **지시와 단순 언급을 구분한다.** "~해 주십시오", "~부탁드립니다", "~했으면 좋겠습니다"
  는 지시다. "그렇군요", "수고하셨습니다" 는 아니다. 애매하면 사용자에게 묻는다.
- **부서를 특정할 수 없으면 `전 부서`** 로 두고, 억지로 특정 과를 고르지 않는다.
- 지시 하나가 여러 부서에 걸리면 `"교육협력과 / 교육지원청"` 처럼 `/` 로 나눈다.

## 검증에서 걸리는 것들

`scripts/verify.py` 가 잡는 항목은 전부 실제로 사고가 났던 것이다.

- 인용문이 회의록에 없음 — 요약하며 문장을 다듬다가 어긋남
- 처리결과가 전부 연결 안 됨 — 최신 회차부터 정리해서 연결할 대상이 없었음
- 기구도에 없는 부서명 — 없는 과를 지어냄
- 부서가 빈 지시 — 필터에 안 걸려서 검색해도 안 나옴
- 화자가 빈 발언 — 4단계를 덜 끝내고 넘어감
